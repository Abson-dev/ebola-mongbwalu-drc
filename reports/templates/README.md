# Word templates

| File | Versioned | Use |
|---|---|---|
| `reference.docx` | yes | Neutral Pandoc/Quarto reference document (default styles) |
| `msf_template.docx` | **no** (git-ignored) | MSF sitrep template. Copy it here locally; `scripts/render.R` uses it automatically when present |

To customise styles, edit the *styles* (not the content) of a copy of `reference.docx` in Word: Heading 1-3, Normal, Table, Caption. See the [Quarto documentation](https://quarto.org/docs/output-formats/ms-word-templates.html).
